# অন্য ওয়েবসাইট থেকে ডোনার ইমপোর্ট

## লক্ষ্য
FPI Helping Hand Society (blood-donation-app-f2509.web.app) সাইটের ডোনারদের আমাদের `donors` টেবিলে আনা — ম্যানুয়ালি কিছু করতে হবে না।

## বর্তমান অবস্থা (যাচাইকৃত)
- ওই সাইটের ডোনার ডাটা Firestore-এ `artifacts/blood-donation-app-f2509/public/data/donors` পাথে আছে এবং anonymous auth দিয়ে পড়া যায়।
- প্রথম পাতাতেই ১২৬ জন পাওয়া গেছে, পেজিনেশন টোকেন আছে — মোট সংখ্যা আরও বেশি (সব পাতা টেনে জানা যাবে)।
- প্রতিটি রেকর্ডে আছে: নাম, ফোন (`contact`), ব্লাড গ্রুপ (`bloodGroup`), এলাকা (`location`), শেষ দানের তারিখ (`lastDonationDate`), মোট দান (`donationCount`)।
- তাদের রেকর্ডে পাসওয়ার্ডও আছে — সেটা **ইমপোর্ট করা হবে না**, বাদ দেওয়া হবে।

## করণীয়

### ১. Admin panel-ে "ওয়েবসাইট থেকে ইমপোর্ট" টুল
নতুন কম্পোনেন্ট `src/components/admin/ImportDonorsFromWeb.tsx`:
- এক ক্লিকে ওই সাইটের সব পাতার ডোনার তথ্য টেনে আনবে (Firestore REST + anonymous token, পেজিনেশনসহ)।
- ডাটা ম্যাপিং: `name → name`, `contact → phone`, `bloodGroup → blood_group`, `lastDonationDate → last_donation`, `donationCount → total_donations`।
- ভ্যালিডেশন: ফোন `^01[3-9][0-9]{8}$` ফরম্যাটে না থাকলে ড্যাশ/স্পেস মুছে ঠিক করার চেষ্টা, না হলে সারিটি "সমস্যা" হিসেবে দেখাবে।
- লিঙ্গ: `looksFemale()` দিয়ে অটো-ডিটেক্ট, বাকিগুলো male (প্রিভিউতে এডিট করা যাবে)।
- ডুপ্লিকেট: আমাদের ডাটাবেসে একই ফোন নম্বর থাকলে "ডুপ্লিকেট" চিহ্নিত — ডিফল্টে বাদ।

### ২. প্রিভিউ ডায়ালগ (আগের bulk upload-এর মতো)
- সব ডোনার টেবিলে দেখাবে: নাম, ফোন, গ্রুপ, লিঙ্গ, শেষ দান — প্রতিটি এডিট/বাদ দেওয়া যাবে।
- স্ট্যাটাস ব্যাজ: নতুন / ডুপ্লিকেট / সমস্যা।
- "যোগ করুন" বাটনে একসাথে সব নির্বাচিত ডোনার `donors` টেবিলে insert হবে (`is_visible = true`), শেষে `["donors"]` invalidate + টোস্ট।

### ৩. যাচাই
- Build OK চেক।
- Playwright দিয়ে admin panel-ে গিয়ে ইমপোর্ট চালিয়ে প্রিভিউতে ডোনার সংখ্যা আর স্যাম্পল ডাটা ঠিক আছে কিনা দেখা।

## টেকনিক্যাল নোট
- কোনো নতুন edge function দরকার নেই — সব client-side fetch (Firestore REST, CORS-মুক্ত)।
- DB schema পরিবর্তন নেই; বিদ্যমান `donors` insert policy ব্যবহার হবে (admin authenticated)।
- ওই সাইটের ডাটা publicly প্রদর্শিত হলেও ডোনারদের সম্মতি আমাদের হাতে নেই — এটা admin-এর (আপনার) সিদ্ধান্ত; চাইলে ইমপোর্টের পর আলাদা যাচাই করে দেখানো/লুকানো যাবে।
